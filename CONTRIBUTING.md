# Contributing to OAAX

Every OAAX-standard repository follows the
[general OAAX contributing guide](https://github.com/OAAX-standard/OAAX/blob/main/CONTRIBUTING.md): where to report
bugs, how to propose changes, and the DCO sign-off (`git commit -s`) every commit needs.

Before opening a pull request, read the repository's `README.md` for its build and test instructions.
